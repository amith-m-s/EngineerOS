# Contributing to EngineerOS

## Prerequisites

Install Node.js, Python, Git, and Docker before starting.

## Local workflow

1. Clone the repository.
2. Follow `GETTING_STARTED.md` for backend and frontend setup.
3. Run the backend and frontend test suites.
4. Run linting and type checks before opening a pull request.

## Pull requests

Please keep changes focused and include:

- what changed
- why it changed
- how it was tested
- any follow-up work

## Reporting issues

For reproducible bugs, include the environment, exact commands, expected behavior, actual behavior, and relevant logs without including secrets.

## Quality bar

Changes should preserve the project's documented architecture and should not claim production guarantees that have not been independently verified.
